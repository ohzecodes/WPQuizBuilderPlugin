# Simple Quiz Plugin

**Simple Quiz Plugin** is a lightweight WordPress plugin that allows you to easily add **single-response** and **multiple-response quizzes** to your posts or pages using shortcodes.

---

## Features

- ✅ Single-response (radio button) and multiple-response (checkbox) support  
- ✅ Simple shortcode integration  
- ✅ Clean and minimal styling  
- ✅ Works with any WordPress theme  
- ✅ lightweight & easy
- ✅ Custom user role with **least privilege** to manage quizzes only 

---

## Installation

1. Download the plugin ZIP file.
2. In your WordPress admin panel, go to **Plugins > Add New**.
3. Click **Upload Plugin**, then choose `simple-quiz-plugin.zip`.
4. Click **Install Now** and then **Activate**.

---

## Usage

Use the shortcode to embed a quiz.

### Example:
```html
